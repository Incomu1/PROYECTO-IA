## Reflexión sobre una propuesta inadecuada

Al ejecutar una primera versión del experimento, encontré un error: el código intentaba usar `.tolist()` sobre las etiquetas de validación, aunque eran una lista de Python. Con apoyo de ChatGPT corregí esa llamada y volví a ejecutar el experimento antes de usar sus resultados. En otra revisión comprobé que el umbral no se recalculara con los datos de prueba, para evitar que la evaluación influyera en las predicciones. Esta experiencia me recordó que debo ejecutar y revisar el código antes de presentar sus resultados. Las métricas describen las inyecciones artificiales; no son evidencia de anomalías reales.
